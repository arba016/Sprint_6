# Sprint_6
Автотесты написаны на Python с использованием Selenium, Pytest и Allure.  
В проекте используется паттерн Page Object Model: локаторы, страницы и тесты вынесены в отдельные директории.

## Проверяемая функциональность

В проекте покрыты следующие сценарии:

1. Проверка выпадающего списка в разделе «Вопросы о важном»:
   - проверяется открытие каждого вопроса;
   - проверяется соответствующий текст ответа;
   - используется параметризация.

2. Проверка позитивного сценария заказа самоката:
   - заказ через верхнюю кнопку «Заказать»;
   - заказ через нижнюю кнопку «Заказать»;
   - заполнение формы заказа;
   - заполнение формы «Про аренду»;
   - выбор даты аренды;
   - выбор срока аренды;
   - выбор цвета самоката;
   - добавление комментария для курьера;
   - подтверждение заказа;
   - проверка сообщения об успешном оформлении заказа;
   - используется параметризация с разными наборами данных.

3. Проверка логотипов:
   - клик по логотипу «Самокат» возвращает на главную страницу;
   - клик по логотипу Яндекса открывает новую вкладку со страницей Дзена.





установка пакетов
pip install -r requirements.txt

добавить пакеты в requirements.txt
pip freeze > requirements.txt

запуситить тесты и получить Allure отчет 

python -m pytest --alluredir=allure_results
allure serve allure_results


очистить прошлые результаты тестов
Remove-Item -Recurse -Force allure_results#
